Image Classification Using CNN with Transfer Learning (ResNet)
Overview

This project implements an image classification model using a convolutional neural network (CNN) with transfer learning based on a pre-trained ResNet architecture. The goal is to leverage learned visual features from large-scale datasets and fine-tune the model on a custom image dataset.

Approach

Used a pre-trained ResNet model as the backbone

Applied transfer learning and fine-tuning for image classification

Trained and evaluated the model on a labeled image dataset

Results

The model achieved 67% accuracy on a held-out test set, demonstrating effective feature transfer while highlighting opportunities for further optimization through data augmentation, hyperparameter tuning, or deeper fine-tuning.

Tech Stack

Python · PyTorch · torchvision · NumPy · matplotlib · Jupyter
